# Portofolio Clarissa Adella Simbolon

Website portofolio pribadi untuk menampilkan profil, keahlian, proyek pembelajaran, dan formulir kontak.

## Teknologi
- HTML5
- CSS3
- JavaScript

## Struktur File
- `index.html` — struktur halaman website
- `style.css` — tampilan dan desain responsif
- `script.js` — fitur mode gelap, filter proyek, dan formulir contoh

## Menjalankan Website
Buka `index.html` menggunakan browser seperti Google Chrome.

## Publikasi dengan GitHub Pages
1. Buka tab **Settings** pada repository.
2. Pilih menu **Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**, lalu klik **Save**.

Catatan: formulir kontak saat ini hanya demonstrasi dan belum mengirim email. Bagian foto profil juga masih berupa inisial dan dapat diganti dengan foto sendiri.
