# Portofolio Clarissa Adella Simbolon

Website portofolio pribadi bertema pink aesthetic untuk tugas pembelajaran SMK jurusan Teknik Jaringan Komputer dan Telekomunikasi (TJKT).

## Isi proyek
- `index.html` — struktur halaman website.
- `style.css` — tampilan dan tata letak responsif.
- `script.js` — fitur mode gelap dan filter proyek.

## Cara menjalankan
1. Unduh atau clone repository ini.
2. Buka folder proyek di Visual Studio Code.
3. Buka file `index.html menggunakan browser.

## Publikasi dengan GitHub Pages
1. Buka tab **Settings** pada repository.
2. Pilih **Pages**.
3. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/ (root)**.
5. Klik **Save**, lalu tunggu proses publikasi selesai.

## Catatan
Bagian proyek berisi contoh yang dapat diganti dengan hasil karya asli. Bagian kontak belum terhubung ke layanan pengiriman pesan.
